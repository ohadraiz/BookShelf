# ארון הספרים שלי - Virtual Home Bookshelf

אפליקציית ווב בעברית לניהול ספריית הספרים הביתית של אוהד ונועה. הארון מוצג כארון עץ עם מדפים, והספרים עומדים עליו כשדרות צבעוניות.

**האתר:** https://ohadraiz.github.io/BookShelf/ · **בטא:** https://ohadraiz.github.io/BookShelf/beta.html

הארון נשמר בדפדפן של כל מכשיר בנפרד. אין חשבון ואין סנכרון. לגיבוי: תפריט > "ייצוא לקובץ library.json".

## הפעלה מקומית
לחיצה כפולה על `start.cmd`, או:
```bash
python -m http.server 8765 --bind 127.0.0.1
```
ואז לפתוח את http://127.0.0.1:8765/app.html. תמיד מאותה כתובת: הדפדפן שומר את הארון לפי הכתובת.

בפעם הראשונה הארון נטען מנקודת ההתחלה, `data/library.json` (137 ספרים). מכאן כל שינוי נשמר בדפדפן.

## מה יש באפליקציה
מסך פתיחה עם דלתות ארון, ארון עם מדפים, רשימה ממוינת, טאב נתונים (יעד שנתי, ספרים לפי חודש, דירוגים, סופרים מובילים), חיפוש מנורמל לעברית (ניקוד, גרשיים, יי/וו), סינון לפי סטטוס, מדף ותגיות, מצב סידור (הזזת ספרים ומדפים, מיון מדף), ביטול פעולות, אזהרת כפילות, "מה לקרוא?", קונפטי בסיום ספר, מצב כהה, תמונות כריכה, ייצוא וייבוא.

## נקודת ההתחלה ושמירת שינויים
