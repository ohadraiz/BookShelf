# פורמט הספרייה - BookShelf Library 1.0.0

זה הפורמט הקבוע לשמירה, לייצוא ולייבוא של ספרייה ביתית.
הקובץ הראשי הוא `data/library.json`. ההגדרה המדויקת נמצאת ב-`schema/library.schema.json`.

## למה ככה
א. **JSON + JSON Schema (טיוטה 2020-12)** - JSON הוא הפורמט הנפוץ ביותר להעברת נתונים בין תוכנות. JSON Schema הוא התקן המקובל לתיאור "מה מותר ומה חובה" בקובץ JSON, ותוכנה יכולה לבדוק לפיו אם קובץ תקין.
ב. **שמות שדות לפי schema.org/Book** - `name`, `author`, `isbn`, `inLanguage`, `numberOfPages`, `datePublished`. זה אוצר המילים שגוגל, ספריות וחנויות ספרים משתמשים בו לתיאור ספרים. כך יהיה קל להעשיר את הנתונים או להעביר אותם לשירותים אחרים.
ג. **תקנים בינלאומיים לערכים** - תאריכים לפי ISO 8601 (`2026-11-04`), שפה לפי BCP 47 (`he`, `en`), ISBN-13.
ד. **מספר גרסה** - `formatVersion` לפי Semantic Versioning. שינוי שלא שובר (שדה חדש) מעלה ל-1.1.0. שינוי שובר מעלה ל-2.0.0, ואז נכתוב גם המרה מהגרסה הקודמת.
ה. **CSV לצד ה-JSON** - `data/library.csv` נפתח ב-Excel וב-Google Sheets, בעברית תקינה.

## המבנה
```json
{
  "format": "bookshelf-library",
  "formatVersion": "1.0.0",
  "exportedAt": "2026-11-04T11:40:00Z",
  "library": {
    "id": "ohad-noa-home",
    "name": "ארון הספרים של אוהד ונועה",
    "owners": ["אוהד", "נועה"],
    "shelves": [{ "id": "s1" }, { "id": "s2" }]
  },
  "books": [
    {
      "id": "b127",
      "work":    { "name": "המוסד - מלחמות הצללים", "author": ["מיכאל בר-זהר", "נסים משעל"], "inLanguage": "he" },
      "copy":    { "shelf": "s9", "position": 26, "status": "shelf", "needsReview": true },
      "reading": { "rating": 4, "tags": ["ריגול"], "endDate": "2026-10-01" }
    }
  ]
}
```

כל ספר מחולק לשלושה חלקים:

| חלק | מה יש בו | למה זה מופרד |
|---|---|---|
| `work` | מה הספר: שם, מחברים, מתרגמים, שפה, ISBN, הוצאה, שנה, עמודים | זהה אצל כל מי שיש לו את הספר הזה. בעתיד, כשהרבה אנשים ישתמשו, אפשר יהיה לשתף את המידע הזה ביניהם |
| `copy` | העותק הפיזי בבית: מדף, מקום על המדף, סטטוס, למי הושאל, תאריך החזרה, "לבדיקה", תמונות כריכה | שייך לספרייה הזו בלבד |
| `reading` | החוויה של הקורא: דירוג, ביקורת, הערות, תגיות, עמוד נוכחי, תאריכי התחלה וסיום | בעתיד, לכל קורא תהיה רשומה משלו על אותו ספר |

## כללים
א. **שדה חסר = לא ידוע.** אין `""` ואין `0` במקום ערך. לכן ספר שעוד לא זוהה פשוט בלי `name` או בלי `author`.
ב. **`author` הוא רשימה** - אדם אחד בכל פריט. ספר של שני מחברים מופיע עם שני שמות.
ג. **`position`** - המקום על המדף, החל מ-1, מימין לשמאל, כמו בארון.
ד. **`status`** - אחד מ: `shelf` (על המדף), `reading` (בקריאה), `read` (קראתי), `want` (רוצה לקרוא), `lent` (השאלתי), `borrowed` (שאול - להחזיר), `given` (מסרתי).
ה. **`rating`** - 1 עד 5. בלי דירוג - השדה לא מופיע.
ו. **מזהים** (`id`) - אותיות לועזיות, ספרות, `-` ו-`_` בלבד. מזהה של ספר לא משתנה לעולם.

## הכלים
כל הכלים ב-`tools/convert.py`, בלי התקנות. אם מותקנת החבילה `jsonschema`, הבדיקה משתמשת בה ובודקת גם מול ה-schema המלא.

| מה רוצים | פקודה |
|---|---|
| גיבוי מהאתר -> פורמט קבוע | `python tools/convert.py from-backup גיבוי.json -o data/library.json` |
| פורמט קבוע -> גיבוי לייבוא באתר | `python tools/convert.py to-backup data/library.json -o backup.json` |
| פורמט קבוע -> גיליון | `python tools/convert.py to-csv data/library.json -o data/library.csv` |
| גיליון -> פורמט קבוע | `python tools/convert.py from-csv data/library.csv -o data/library.json` |
| בדיקת תקינות | `python tools/convert.py validate data/library.json` |
| בדיקת ההמרות | `python tools/test_convert.py` |

ההמרה לא כותבת קובץ לא תקין. אם יש שגיאה, היא מדפיסה אותה ועוצרת.

## עמודות ה-CSV
`id, title, subtitle, authors, translators, language, isbn, publisher, published, pages, shelf, position, status, person, due_date, needs_review, rating, tags, current_page, start_date, end_date, review, notes`

א. `shelf` הוא מספר המדף (1, 2, 3...), לא המזהה.
ב. כמה ערכים בתא אחד (מחברים, מתרגמים, תגיות) מופרדים ב-`; `.
ג. `needs_review` - `yes` או ריק.
ד. הקובץ נשמר ב-UTF-8 עם BOM, כדי ש-Excel יציג עברית נכון.

## ההבדלים מקובץ הגיבוי של האתר
קובץ הגיבוי של האתר (`app: bookshelf, version: 2`) הוא פורמט פנימי של האפליקציה. ההמרה בין שני הפורמטים לא מאבדת מידע, חוץ משני הבדלים:
א. `pos` באתר (1000, 2000...) הופך למקום על המדף (1, 2...). הסדר נשמר.
ב. המחבר באתר הוא טקסט אחד. שלושת הספרים עם כמה מחברים מפוצלים לפי רשימה קבועה בתוך `convert.py` (`AUTHOR_SPLITS`). פיצול אוטומטי לפי " ו" לא בטוח, כי למשל "ג'ון ויליאמס" הוא אדם אחד.
