### זרימת קוד (שינוי באפליקציה)
1. משנים את `app.html` בתיקייה המקומית.
2. בודקים מקומית: `python tools/make_test.py` ופתיחת `test.html`.
3. שומרים ב-Git (commit) ומעלים ל-GitHub (push).
4. מפרסמים את `app.html` ל-Artifact. רק מגרסה שכבר שמורה ב-GitHub, ורק באישור של אוהד.
5. בודקים באתר החי שהכל עובד.

אף פעם לא משנים את הקוד ישירות באתר, אחרת GitHub והאתר ייפרדו.

### זרימת נתונים (גיבוי)
1. באתר: תפריט > ייצוא גיבוי. או ש-Claude קורא את מסד הנתונים ישירות.
2. שומרים את הקובץ ב-`data/backups/live-YYYY-MM-DD.json`.
3. ממירים: `python tools/convert.py from-backup data/backups/live-YYYY-MM-DD.json -o data/library.json`, ואז `to-csv`.
4. שומרים ב-Git ומעלים.

מתי: אחרי כל עבודה גדולה על הספרים, ולפחות פעם בחודש.

שחזור (רק במקרה חירום): `to-backup` מ-`data/library.json`, ואז באתר: תפריט > ייבוא גיבוי. הייבוא מחליף את כל הארון.
