# מעקב גרסאות - ארון הספרים שלי

הקובץ מתעד גרסאות ושינויים משמעותיים באפליקציה. מספר גרסת האפליקציה נפרד מגרסת פורמט הנתונים (`formatVersion`). לתצוגה בדפדפן: [דף מעקב הגרסאות](versions.html). בעת עדכון גרסה, מעדכנים גם את הדף.

## 0.1 - נקודת התחלה

4 בנובמבר 2026

גרסה 0.1 מסמנת את מצב הפרויקט הקיים ביום זה ומשמשת נקודת התחלה למעקב הגרסאות. היא אינה קובעת ששינויים עתידיים כבר שוחררו.

- ארון ספרים בעברית עם מדפים, תצוגת רשימה ונתוני קריאה.
- חיפוש, סינון, כרטיסי ספרים, סידור מדפים, תמונות כריכה וייבוא וייצוא.
- עבודה מקומית עם נתונים בדפדפן ונקודת התחלה ב-`data/library.json`.
- אתר ראשי ובטא עם אחסון נפרד, ואפשרות התקנה כאפליקציה.

שינויים עתידיים יתועדו כאן לפי גרסה ומועד השחרור שלהם. הוראות הבדיקות והשחרור נמצאות ב-[הוראות הפרויקט](../AGENTS.md), ותוכנית הפיתוח ב-[תוכנית העבודה](ROADMAP.md).
